# Итоговая работа: Автоматизация тестирования OpenCart

## Описание
Репозиторий содержит итоговую работу по развертыванию веб-приложения OpenCart 4 в Docker и написанию автотестов на Selenium (Python + Pytest).

## Требования
- Docker Desktop
- Python 3.10+
- Microsoft Edge + msedgedriver

## Инструкция по запуску сайта
1. В папке проекта находится файл `docker-compose.yml` и `.env`.
2. Запустите контейнеры:
   ```bash
   docker compose up -d
3. Сайт будет доступен по адресу: http://192.168.0.251:8081
4. Админка: http://ТВОЙ_IP:8081/administration (логин: user, пароль: bitnami).

## Инструкция по запуску тестов 
1. Установите зависимости:
   ```bash
   pip install selenium pytest pytest-html webdriver-manager
2. Запустите тесты:
   ```bash
   python -m pytest test_opencart.py -v
3. Для генерации HTML-отчета:
    ```bash
   python -m pytest test_opencart.py -v --html=report.html --self-contained-html

##Список реализованных тестов (10 шт.)
1. Проверка заголовка главной страницы.
2. Проверка отображения логотипа.
3. Наличие строки поиска.
4. Поиск существующего товара (позитивный).
5. Поиск с пустым запросом (негативный).
6. Проверка кликабельности навигационного меню.
7. Наличие футера на странице.
8. Проверка перехода на страницу авторизации админки.
9. Авторизация в админке с неверным паролем (негативный).
10. Успешная авторизация в админке (позитивный).
